# SkillCraft Technology - Internship Tasks

## About
This repository contains all 4 Python projects completed during my
Software Development Internship at SkillCraft Technology.

## Tasks Completed

### Task 01 - Temperature Converter
- Converts temperatures between Celsius, Fahrenheit and Kelvin
- Interactive menu based program

### Task 02 - Number Guessing Game
- Generates a random number and challenges the user to guess it
- 3 difficulty levels - Easy, Medium and Hard
- Gives hints after every wrong guess

### Task 03 - Sudoku Solver
- Automatically solves Sudoku puzzles
- Uses Backtracking Algorithm
- 3 built-in puzzles - Easy, Medium and Hard

### Task 04 - Web Scraper
- Extracts product names, prices and ratings from books.toscrape.com
- Saves scraped data to a CSV file

## Technology Used
- Language : Python 3.14
- Libraries : requests, beautifulsoup4
